# Pizzeria Integration Platform

A backend integration platform for restaurant orders using Java,
Spring Boot, Apache Camel, and Red Hat integration technologies.

## Overview

This project explores enterprise integration patterns through a
restaurant order processing use case.

The application will receive, validate, process, and route orders
to different business flows.

## Objectives

- Build REST APIs for restaurant orders.
- Implement integration routes using Apache Camel.
- Apply Enterprise Integration Patterns (EIPs).
- Validate orders and calculate order totals.
- Implement error handling and automated tests.
- Explore Red Hat integration technologies.

## Technology Stack

- Java 21
- Spring Boot
- Apache Camel
- Maven
- REST and JSON
- JUnit
- Docker

## Planned Integrations

- Red Hat build of Apache Camel for Spring Boot
- Red Hat AMQ
- Red Hat OpenShift

## Project Status

Initial development.

## Learning Goals

Build practical backend integration skills and explore enterprise
integration architecture, messaging, testing, and deployment.
